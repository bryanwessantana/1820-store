# 1820 Store

A **1820 Store** é uma galeria digital especializada em arte impressa de alta curadoria. Focamos em levar para as paredes de nossos clientes obras selecionadas — como as coleções Middle-earth, SUD e Classics — garantindo a máxima qualidade através de impressão Giclée em papel algodão e molduras artesanais.

## 🚀 Tecnologias
Este projeto foi desenvolvido com uma stack moderna e performática:
- **Framework:** TanStack Start (React + Vite)
- **Estilização:** Tailwind CSS
- **Animações:** Framer Motion
- **Componentes:** shadcn/ui
- **Roteamento:** TanStack Router

## 🛠️ Funcionalidades
- Catálogo navegável por coleções.
- Guia interativo de tamanhos (escala real).
- Visualizador de molduras em ambiente real.
- Cálculo de frete e prazos.
