The **1820 Store** is a premium, high-performance e-commerce storefront template specialized in curated, handmade framed fine art prints. This application was architected with a strong focus on rendering speeds, fluid animations, and a seamless visual shopping experience across exclusive art collections.

The platform showcases advanced frontend architectures, leveraging cutting-edge routing solutions and performance-optimized asset compilation to bridge the gap between heavy visual media and rapid interaction times.

🌐 **[Live Demo on Vercel](https://1820-store.vercel.app/)**

---

## ✨ Key Features

* **Collection-Based Navigation:** Intuitive browsing across dynamic artistic categories.
* **In-Room Frame Preview:** High-fidelity simulation of art pieces displayed within real-world environments.
* **Interactive Sizing Guide:** Dynamic component layout to guide users through dimension choices.
* **Simulated Freight & Logistics:** Real-time shipping cost feedback logic.
* **Fully Responsive UI:** Fluid layouts meticulously designed for desktop, tablet, and mobile displays.

## 🚀 Getting Started

### Prerequisites
* [Bun](https://bun.sh/) runtime engine installed locally.

### Installation & Execution

1. Clone this repository to your local machine:
```bash
   git clone [https://github.com/bryanwessantana/1820-store.git](https://github.com/bryanwessantana/1820-store.git)
```

Navigate into the project directory:
```bash
cd 1820-store
```

Install project dependencies using Bun:
```bash
bun install
```

Start the local development server:
```bash
bun run dev
```

## 🛠️ Tech Stack & Ecosystem

* **Styling Engine:** Tailwind CSS

Deployment Platform: Vercel / Cloudflare Ecosystem
